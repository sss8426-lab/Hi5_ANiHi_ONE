운영환경 진단

D1, R2, 로그인 권한이 실제 운영 환경에서 정상 동작하는지 한 번에 확인합니다.

최종 진단미실행

연결 상태

단순 설정값이 아니라 실제 Worker API 응답을 기준으로 표시합니다.

실제 읽기·쓰기 진단

마스터만 실행할 수 있습니다. 임시 probe 데이터를 만들고 즉시 삭제하여 D1/R2 동작을 검증합니다.

아직 진단을 실행하지 않았습니다.

운영 전 체크 기준

  1. D1 읽기와 D1 쓰기/삭제가 모두 성공해야 합니다.
  2. R2 쓰기·읽기·삭제가 모두 성공해야 합니다.
  3. 마스터 계정이 SUPER_ADMIN으로 인식되어야 합니다.
  4. 모든 진단이 성공한 뒤 실제 학원 자료 업로드를 시작합니다.
