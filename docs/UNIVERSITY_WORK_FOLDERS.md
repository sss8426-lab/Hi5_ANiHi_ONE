# 대학합격 우수작·우수작 대학 폴더 (2026-10-12)

- 상담용 홈 공모전·실기대회 아래의 중복 작품 메뉴만 제거한다. 기존 작품 자료/직접 경로는 유지한다.
- 대학합격 로드맵의 대시보드 메뉴와 화면을 제거한다. 최초 진입 및 이전 dashboard 주소는 학생 관리로 연결한다.
- 로드맵 작품 메뉴: 대학합격 우수작·우수작. 기존 admitted 모음은 대학합격 우수작, university 모음은 우수작으로 표시한다. 기존 collectionType/ID/이미지는 유지한다.
- 사용자가 제공한 대학·교육기관 목록은 약칭 중복을 제외한 68개다. 울산대학교와 4개 예술교육기관도 포함한다. 명시된 캠퍼스 표기를 보존하며 예원예술대학교는 요청대로 전북·경기캠퍼스 통합 이름을 사용한다.

## 실제 폴더 저장

MASTER가 작품 모음을 열면 동일 출처 POST `/api/data-core/awards/university-folders`를 호출한다. 기존 award workspace의 `data_records`에 두 모음당 68개 대학 루트 폴더를 저장한다. GET 조회는 폴더를 생성하지 않는다.

폴더는 기존 공모전 수상작과 같은 생성/연도 하위 폴더/단계별 경로/정렬/이미지 업로드/확대/휴지통/감사 로그/권한 경로를 사용한다. 새 저장소나 DB 테이블을 만들지 않는다. 연도와 실기유형 등의 하위 폴더는 기존 + 하위 폴더로 생성한다.

생성은 MASTER만 수행하고 기존 구성원은 기존 자료실 권한에 따라 사용한다. 안정적인 이름 기반 ID와 INSERT OR IGNORE로 반복/동시 요청의 중복을 방지한다. 기존 약칭 폴더를 재사용하고 원래 ID와 메타데이터는 수정하지 않는다. 휴지통에 있는 기본 폴더도 자동 복원하거나 재생성하지 않는다. 생성과 감사 기록을 같은 batch에 넣는다. 한 번에 80개 SQL 문장을 실행하므로 일부 batch 이후 오류가 발생해도 다시 열어 재시도할 수 있다.

## 검증과 운영 경계

- npm ci, npm run build, npx tsc --noEmit, 수정 browser JS node --check 통과.
- 관련 테스트 40개: 폴더/업로드/권한/독립 모음/경로/캐시/슬라이드쇼, 신규 기본 목록/동시 생성/중복/휴지통/약칭 재사용 검증.
- scripts/check-university-work-folders-browser.mjs: 격리된 합성 Worker D1/R2에서 1440px/390px, 대시보드 제거/기본 학생 관리/중복 메뉴 제거/68+68 폴더/연도 하위 생성/경로 표시 검증.
- 운영 데이터/이미지 수정 또는 배포는 이 검증에 포함하지 않는다. 운영 폴더는 새 버전 배포 후 MASTER가 작품 모음을 열 때 준비된다.
