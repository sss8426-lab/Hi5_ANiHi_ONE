# 초등 커리큘럼 첫 화면

승인된 시안에 따라 `꿈 그림의 시작 커리큘럼` 안에 이미지와 설명이 있는 폴더 카드 세 개를 표시한다.

| 순서 | 폴더명 | 경로 |
|---|---|---|
| 1 | 꿈 그림 기초 | `/data-core/curriculum/start/drawing` |
| 2 | 만화그리기 기초 | `/data-core/curriculum/start/comics` |
| 3 | 디자인하기 기초 | `/data-core/curriculum/start/design` |

기존 과정 카드의 3:2 이미지, 설명, 화살표와 반응형 배치를 재사용한다. 새 그림은 승인 시안을 참고해 내장 이미지 생성 도구로 제작한 초등 수업 안내 그림이다. 실제 학생 작품이나 수업 수로 표시하지 않는다. 생성 프롬프트는 `public/data-core/assets/curriculum/start-prompts.json`에 기록한다.

이 세 경로는 폴더 진입 화면이다. 아직 등록된 수업자료가 없어 자료 없음 안내를 표시하며, 실제 수업이나 DB 레코드를 임의로 만들지 않는다. 후속 교재 등록은 기존 중앙 커리큘럼 저장·권한 구조를 사용해야 한다. content의 중앙 수업 목록·인쇄와 design의 기존 과정은 유지한다.

클라이언트 초기 화면 판별과 서버 HTML 경로를 함께 추가하여 직접 URL 진입, 새로고침, 뒤로 가기가 같은 화면을 표시하도록 한다. 기존 화면의 로그인 흐름과 중앙 수업자료 API의 서버 권한 검사를 유지한다.

검증 기록은 해당 PR과 `outputs/elementary-curriculum/browser/results.json`에서 확인한다. 운영 반영 결과는 PR 병합 및 배포 후 별도로 기록한다.

## 적용 전 검증

- `npm run build`, `npx tsc --noEmit`, 변경된 브라우저 JS 구문 검사 통과.
- 커리큘럼·상담 연결 회귀 검사 15개 통과. 기존 중앙 자료의 권한·등록·인쇄 동작 검사를 포함한다.
- 브라우저에서 1920, 1440, 1024, 768, 390, 320px 화면의 카드 순서·이미지 로딩·가로 넘침을 확인했다.
- 마스터·캠퍼스 관리자·교사 모의 계정에서 폴더 클릭, 직접 진입, 새로고침, 뒤로 가기와 기존 과정 화면을 확인했다. 오류와 데이터 변경 요청은 없었다.
- 브라우저 검증은 격리된 모의 API를 사용했으며 실제 운영 계정으로 수업자료를 등록한 검증은 아니다.
