# 휴무요일 생략 출석부 인식 복구

기준 main: `23c8ee7bacbfe8c2b5534f7a8bffdb91b4839c5e` (PR #231).

## 원인

첨부된 실제 workbook은 7개 시트 모두 휴무요일의 날짜를 생략하고, 폭이 좁은 빈 열로 주를 구분한다. 기존 연속 1~31일 인식기는 첫 생략 날짜에서 중단하여 0개 시트로 표시했다. 날짜 머리글의 `이전 날짜 + 1`, 공유 수식, 필터용 정의 이름도 함께 처리해야 다음 달 생성이 가능하다.

## 변경

- 기존 연속 날짜 인식기를 유지하고 실패한 경우에만 주간 양식 adapter를 사용한다. 명시적인 날짜/요일, 병합 수업칸, 좁은 빈 구분 열을 함께 검증한다.
- 원본 첫 28일의 모든 반복 요일 근거로 운영 요일과 슬롯 수를 구한다. 휴무요일을 추측해서 수업일로 추가하지 않는다. 이 adapter는 원본처럼 휴무 날짜를 생략한다. 기존 31일 연속 양식의 정책은 바꾸지 않는다.
- 원본 날짜 숫자에 일부 오기가 있을 때 명시적인 요일 순서와 첫/마지막 날짜, 최소 75% 일치 근거가 있는 경우만 제한적으로 복원한다. 실제 파일의 5개 오기는 생성 전·후 경고한다. 원본 자체는 수정하지 않는다.
- 다음 달의 실제 날짜에 맞춰 주간 구분 열과 수업칸을 재배치한다. 학생 정보 열, 행 높이, 원본 스타일, 꼬리 영역과 인쇄 범위를 보존한다. 주간 양식은 명시된 인쇄 영역 안의 학생만 대상으로 하며 그 밖의 기록을 등록 학생으로 혼합하지 않는다.
- 지원하는 로컬 수식은 COUNTIF와 숫자/셀 참조 연산이다. 공유 수식을 먼저 해제하고 실제 열 이동에 맞춰 참조를 연결한다. 날짜 머리글 수식은 실제 달력 값으로 교체한다. 알 수 없는 함수/개체/부분 병합은 조용히 변환하지 않고 차단한다.
- 기존 `#REF!` 오류는 임의의 숫자로 바꾸지 않고 경고한다. Excel 재계산을 요청하며 웹 미리보기에 오래된 집계 캐시를 표시하지 않는다.
- 이동 전 수식 주소가 남아 있는 계산 체인(calcChain)은 생성본에서만 관련 관계/콘텐츠 타입과 함께 제거해 Excel이 다시 만들도록 한다. 원본 chain/파일은 그대로다. 그 외 비대상 ZIP 파트는 보존한다.
- D1/R2/FAMILY, 학생·계정 데이터, API 변경 및 migration 없음. 업로드 workbook은 브라우저 메모리에서만 처리한다.

## 검증

- `tests/attendance-sparse.test.mjs`: 휴무 생략, 주간 구분, 토요일 슬롯, 참조 이동, 공유 수식, 원본 bytes/ZIP 보존, 날짜 오기, 인쇄 외 기록, 2월/윤년 및 재업로드, 실패 안전 정책.
- `scripts/check-attendance-sparse-private.mjs`: 명시적으로 지정한 로컬 실제 파일만 읽기 전용 검증. 이름/학교/파일 경로/실제 셀 내용/생성 workbook은 기록하지 않는다. 요일 검토가 필요한 행은 테스트용으로만 확인하며 실제 학생 시간표의 정확성을 검증했다고 표현하지 않는다.
- `scripts/check-attendance-browser.mjs`: 기존 권한/생성/다운로드/인쇄 회귀에 주간 양식과 경고 표시, 선택적 실제 파일 인식·생성·다운로드 재열기를 추가했다. 실제 파일 스크린샷/생성본을 저장하지 않는다. 서버 인증은 합성 context이며 운영 로그인 검증과 구분한다.
- 최종 검사/PR/Preview/production 결과는 PR evidence에 기록한다.
- 로컬 실제 파일: 7개 시트/인쇄 영역 안 220명 인식. 2026-10, 2027-02, 2028-02 각각 7개 생성 및 재업로드, 각 시트 예상 A4 1장. 원본 hash와 인쇄 영역 밖 셀 무변경. 수업요일 검토 5명은 테스트용 확인만 했으며 담당자의 실제 요일 확인은 남는다.

## 제한

새 달의 공휴일/보강일을 자동 추측하지 않는다. 실제 수업요일 확인, 원본의 끊어진 집계 수식 수정, Excel 앱 재계산 및 물리 프린터 확인은 담당자 검수가 필요하다. 이 변경은 모든 임의 Excel 양식을 지원한다는 의미가 아니다.
