- 32개 신규 생성, D002/D012/D020 기존 승인 이미지 유지. 기존 35개 cover, portrait,

  인터넷 이미지 다운로드, 실제 로고 삽입, 실제 학생/보호자 사진 사용 없음.

  `roadmap-image-v2-provenance.json`에 기록했다. 모델 ID는 도구가 제공하지 않아 추정하지 않는다.
- 카드 640x480, 신규 상세 1440x1080, 모두 4:3 WebP. 승인 3개 상세는 기존 1600x1200 원본을 사용한다.
  색보정/내용 합성 없이 크기·인코딩만 변환했다. 그림 전체가 보이도록 contain을 유지한다.
- 카드 각각 80,000 bytes 미만, 신규 상세 각각 350,000 bytes 미만. 신규 카드 합계 1,691,150 bytes,
  신규 상세 합계 5,712,242 bytes. 이는 전송 자산 크기이며 실제 접속 속도 측정값은 아니다.
- 카드 lazy, 선택한 상세 hero만 eager/high priority, 명시적 dimensions와 장면 설명 ALT를 사용한다.
