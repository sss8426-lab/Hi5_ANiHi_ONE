# 출석부 → 꿈이음 반영 (2026-10-15)

사용자 요청: 출석부를 만들면 그 내용이 꿈이음(아이소식·반소식·선택전달의 반·학생 목록)에 반영되어야 한다. 출석부와 꿈이음이 다르면 다른 곳을 보여 주고, 학생마다 체크해서 적용할지 정하게 한다.

## 동작
- **출석부 화면(업무 › 출석부)**
  - 출석부를 만들면 그 달 명단을 저장합니다(`autoCreate:false`). 이때 새 반·학생은 바로 만들지 않습니다.
  - 결과 아래에 **출석부 → 꿈이음 반영** 표가 열립니다.
- **꿈이음 아이소식 맨 위(원장·관리자)**: 이번 달 출석부와 다른 곳이 있으면 "N월 출석부와 다른 곳 N곳" 알림 줄이 보입니다. 누르면 같은 표가 열립니다.
- **표의 줄**
  | 줄 | 내용 | 기본 체크 |
  |---|---|---|
  | 새 학생 | 꿈이음에 없는 학생을 출석부 반으로 등록. 두 반에 있는 같은 아이는 한 명으로 등록 | 체크 |
  | 반 이동 | 꿈이음 반이 출석부와 다르면 출석부 반으로 옮김. 출석부 두 반 중 하나에 이미 있으면 그대로 둠 | 체크 |
  | 재원으로 되돌리기 | 휴원·퇴원 학생이 출석부에 있음 | 체크 |
  | 출석부에 없는 재원생 → 휴원 | 휴원이 되면 출석체크와 출결기에서 빠짐 | **체크 안 함** |
  | 출석부에 없는 반 숨기기 | 재원생이 남아 있으면 숨기지 않음. 숨긴 반은 꿈이음 반 목록에서 빠짐 | 체크 |
  | 확인 필요 (동명이인) | 체크 대상이 아님. 출결 설정 › 명단 정리에서 연결 | — |
- 반별·전체 체크박스로 고르고 **선택한 N건 적용** 또는 **적용 안 함**을 누릅니다.
  - "적용 안 함"을 고른 줄은 그 달에는 다시 묻지 않습니다. "적용하지 않기로 한 줄"을 열고 **다시 보기**를 누르면 되돌릴 수 있습니다.
- 무엇이든 적용하면 출석부의 반은 모두 꿈이음에 만들어집니다(반소식 대상이 되도록).
  - 출석부 줄과 새 학생도 연결됩니다.
  - 등하원 번호는 새로 생긴 학생에게만 새로 줍니다.
- 원장·관리자만 할 수 있습니다(서버 403). 모든 적용은 `family_audit_logs`에 기록됩니다(`attendance_roster.sync`).

## API
| 요청 | 설명 |
|---|---|
| `GET /api/kkumeum/attendance/roster-sync?campusId=&month=&summary=1` | 다른 곳 목록. `summary=1`이면 개수만 |
| `POST /api/kkumeum/attendance/roster-sync` | `{campusId, month, updatedAt, apply:[], skip:[], unskip:[]}` |
| `PUT /api/kkumeum/attendance/roster` | `autoCreate:false`면 새 반·학생을 만들지 않고, 응답 `sync.pending`에 다른 곳 개수를 담음 |

`autoCreate`가 없을 때(예전 방식)는 지금처럼 바로 등록합니다.
