### 부족한 연결 및 검수 대상

- 대학 후보 0개 또는 공개 요강 0개인 직업은 없다. 실제 빈 상태는 `연결 대학 검수 필요`로 표시한다.
- D035: 14개 조합/20건으로 상대적으로 적다. 인문 융합과 시각 제작 트랙 구분은 교육과정 검수 필요.
- D028: 15개 조합/38건. 공간디자인 후보가 중심이며 전시·VMD 전용 과정으로 확정하지 않는다.
- D029: 18개 조합/48건. 공간디자인과 무대미술의 교육 차이를 별도 확인해야 한다.
- D032·D033: 각각 22개 조합, 비율 확인 필요 29건/31건. 단순 비율로 표시할 수 없는 전형이 많다.
- D003·D004·D016: 문화콘텐츠·문예창작 범주가 연결되어도 작화 실기 전형을 보장하지 않는다. 시각 자료 읽기·콘티·그림책 준비와 실제 입시전형을 구분한다.
- D009~D012: 명칭에 게임 소프트웨어·게임공학·컴퓨터공학이 있고 미술 트랙이 명시되지 않은 기존 row 16개를 각 직업의 화면 후보에서 보류한다. 원본 삭제는 아니다. 미술 트랙이 함께 명시된 복합 명칭은 기존 탐색 후보로 유지한다.
- 게임공학에 미술 교육이 전혀 없다고 단정하는 규칙이 아니다. [커리어넷 게임공학과](https://info.career.go.kr/cloud/m/major/uView?seq=21)도 복합 분야임을 설명한다. 세부 그래픽 교육이 확인되지 않은 전공을 자동 추천하지 않기 위한 보수적 표시 제한이다.
- 불명확한 게임학부·융합학부의 세부과정 검수까지 완료됐다고 보지 않는다. 애매한 대학/캠퍼스 자동 매칭과 학과 suffix 제거 없음.
- 연결 요강의 실기유형 필드는 빈 값 0건이지만, 모든 실제 시험 과제를 검수했다는 뜻은 아니다.
- 모든 직업에 mapping review가 남는다. 상세 요강을 읽을 수 있는 것과 공식 모집요강 검수 완료는 별개다.
- D012의 UI/UX 표기를 시각디자인·게임그래픽·디지털미디어디자인 범주로 구체화했다. 해당 범주만으로 특정 대학의 실제 세부전공을 만들지 않는다.

## 실기향상 로드맵

제목: **실기향상 로드맵**

부제: 현재 실기에서 목표 전공까지, 필요한 성장을 순서대로 확인해요.

1. 기초 표현력: 기존 foundation의 관찰·인체·투시·색채 등.
2. 전공 기초: 직업별 표현 요소와 시각 언어.
3. 전공 심화: 직업별 장면·프로젝트·설계 결합.
4. 입시 실기 적용: 기존 preparation과 실제 지원 전형의 과제·제출 조건.
5. 실전 완성도: 직업별 점검 기준 + 결과물 + 주제 해석·시간 배분·작품 설명.

PD는 콘티 읽기와 작품 피드백, 연출은 장면·색감의 일관성, UI는 정보 가독성,
제품·공간은 구조·모형 표현으로 구분했다. 재학 연차나 고정 수강 기간을 뜻하지 않는다.
원본 workbook 파일명/provenance는 추적을 위해 보존하지만 공개 track.structure의 연차 표현은 제거했다.
수업 준비 그룹도 공유 track.focus 대신 직업별 specialization을 사용한다.
현재 실력을 자동 평가하거나 대학별 출제 과제를 만들어내지 않는다.
원본 파일을 다시 import해도 `scripts/roadmap-career-review.json`의 allowlist 편집을 재적용한다.

## 상담 흐름과 UI

- 직업 카드 → 설명/차이/결과물 → 관련 전공 → 대학·입시 → 성적·실기 → 실기향상 로드맵 → 나에게 맞는 수업.
- paginated API는 저장된 요강 row를 먼저 표시한다. 대학 순위가 아니며 원본 대학 row에 요강 ID를 임의 부착하지 않는다.
- 한 페이지 네 개 유지. 검수된 기존 row는 공식 HTTPS 출처로, 공개 요강 row는 기존 상세 dialog로 연다.
- 학년도·전형·모집인원·성적/실기·실기유형·경쟁률·접수/시험 일정·출처는 기존 public detail contract 사용. 불완전한 반영식이나 없는 값은 확인 필요.
- 상단 흐름은 career hash를 유지한 채 스크롤한다. 네 개 이름 변경은 옛 이름 검색을 보존한다.
- 공모전/대학합격/자료보관함/블로그/인스타/꿈이음 데이터 흐름과 권한 변경 없음.
