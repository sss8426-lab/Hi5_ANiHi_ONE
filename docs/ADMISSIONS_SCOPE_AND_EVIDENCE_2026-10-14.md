# 67개 기관 범위 및 공식 입시 근거 (2026-10-14)

## 실제 적용 범위

사용자가 지정한 67개 기관 및 지정 캠퍼스를 `public/data-core/university-scope-model.js`에 관리한다. 학교 원본은 삭제하지 않는다. 새 D1 `data_records` 기록은 `admissions-university-scope:current`이며 revision CAS로 숨김/복원/전체 해제를 저장한다. 이전 74개교 기록도 보존한다. 새 범위 기록이 있으면 새 범위만 대학 관리 목록과 학생 추천에 적용하며 과거 합격사례 연결은 보존한다. 캠퍼스 불명은 보수적으로 제외한다. 계명대 대명은 직접 소재지를 확인한 영상애니메이션과 및 명시된 대명 행만 자동 분류한다.

마스터만 POST `/api/admissions/university-scope`를 사용한다. actions는 `preview`, `apply`, `restore`, `hide`, `reset`. 변경은 `expectedRevision` 필수. hide/restore는 실제 원본 ID만 허용한다. UI에 목록 범위 적용, 숨긴 대학 보기, 선택 복원, 전체 숨김 해제를 제공한다. 누락한 3개 비대학 기관은 수치 없는 기본 항목만 추가할 수 있다.

## 공식 근거 원본과 검증 수준

67개 기관의 공식 출처를 조사했다. 카탈로그에는 캠퍼스 분리 68개 출처 항목과 391개 원문 확인 수치/미공개 항목이 있다. 391은 평균 성적 개수가 아니며 평균, 최저, 각종 컷, 점수, 경쟁률, 모집인원 등을 포함한다. 일부 모집요강은 `link_only`, 결과는 `not_yet_inspected`이다. 전체 학과/전형 본문·산식 검증 완료가 아니다. 공개하지 않은 평균을 추정하지 않는다.

`public/data-core/official-admissions-evidence.json`은 배포에 포함된 검토 카탈로그이며 마스터 POST `/api/admissions/university-evidence` `{action:'apply',expectedRevision}`로 D1의 별도 보호 기록 `admissions-official-evidence:current`에 영속화한다. 요청에서 임의 카탈로그를 받을 수 없다. 개별 대학 원본 R2 상태, 원본 학생 데이터는 이 작업으로 바뀌지 않는다. 원문 확인 결과와 기존 acceptedStats 입력값은 명확히 분리해서 표시한다. 기존 입력값을 공식 평균으로 간주하지 않는다. 새 카탈로그가 배포되면 적용 버튼으로 새 revision을 저장한다.

- 청강: 공식 등록자 최저를 평균으로 사용하지 않는다.
- 건국 글로컬: 실기100% 전형 내신 미공개 수치를 채우지 않는다.
- 상명 천안: 공개 2026 등급은 진로선택 제외, 2027 전형 환산은 진로선택 포함이므로 직접 비교 보류.
- 한성: 2027 AI융합디자인학부 개편, ICT디자인 야간 폐지, 게임상황표현 미실시가 공식 요강에 있다. 기존 학과명을 최신이라고 보장하지 않으며 출처 카탈로그에 변경 내용을 기록한다.

## 학생 추천

기존 임의 안정/적정/소신 합격확률 % 대신 공식 평균과 대학별 동일 기준 환산등급을 비교한다. ±0.3은 표시 구간이지 합격선/확률이 아니다. 실기/면접/수능최저/자격은 별도 확인한다.

현재 신규 공식 평균 후보는 한국영상대 2027 수시1 실기 애니메이션/웹소설/웹툰PD 3개 학과만 조건부 지원한다. 2026 및 2027 공식 산식을 대조했고 교과40%임을 확인했다. 실기100% 학과는 내신 기반 추천 대상에서 제외한다. 다른 학교는 공식 수치가 있어도 대학별 환산식·모집집단·전형·기준이 확인되기 전까지 pending으로 유지한다. 기존 중부/서원 검증 프로그램에 올바른 admissionBenchmark가 등록되면 기존 검증 엔진도 재사용한다.

학생의 `admissionsProfile={year,season,scale,schoolStatus,complete}`를 명시적으로 저장해야 한다. 상세 학생부 과목/단위/원점수가 부족하면 비교 보류한다. 한국영상은 1-1~3-1 다섯 학기 단위가중 후 우수 두 학기를 동일50%로 반영한다. 실제 결측학기는 공식 규칙대로9등급이지만 complete 체크는 사용자 확인이며 자료가 실제 완비되었다는 자동 검증이 아니다. 5등급제 및 미지원 학년은 9등급제로 임의 환산하지 않는다. OCR 등 부분 성적 변경은 과거 complete 확인을 해제한다.

조회 결과의 `_universityScope`, `_universityRecommendationExcludedIds`, `_universityEvidence`는 서버 파생값이며 전체 `/api/data` PUT으로 위조할 수 없다. 별도 기록과 content API도 generic 기록 변경에서 보호된다.

## 검증

- 명시적 성적 프로필·공식 출처·지표·단위·모집집단·학년도·기준 일치 tests
- 숨김/복원/전부 해제/기존74개교 fallback, ID 재사용 방어
- master/campus/teacher 권한 및 동일 출처
- CAS 동시 변경 방어, D1 감사 실패 원자적 rollback
- 원본 대학/학생/기존 합격사례 불변
- 실제 학생 성적을 테스트용으로 수정하지 않는다

운영 배포와 실제 적용은 별도로 확인해야 한다. 이 문서와 로컬 테스트 성공만으로 운영 완료를 주장하지 않는다.
