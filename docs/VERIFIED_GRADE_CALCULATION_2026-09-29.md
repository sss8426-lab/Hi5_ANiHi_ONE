# 대학별 학생부 교과 환산: 첫 운영 버전

## 경계

- 기존 대학 합격 로드맵의 대시보드·지원전략에 동일한 과목별 입력/환산 화면을 연결한다. 별도 앱, DB, R2 저장소는 만들지 않는다.
- 기존 평균 내신/임의 실기점수 기반 합격 가능성 퍼센트를 이 두 화면에서 사용하지 않는다. 환산점수는 합격 확률이 아니다.
- 2027 수시, 국내 고교 9등급제 석차등급 및 해당 진로선택 성취도에 한정한다. 2028, 5등급제, 정시, 검정고시·해외고는 별도 검증 전 자동 산출을 차단한다.
- 자동 환산은 **2개 대학, 8개 학과·전형**이다. 74개 대학 전체의 환산식 검증을 끝낸 버전이 아니다.
- 관리 대학 74개 제한/삭제 상태, 수시·정시 입시요강, 대학 원본 레코드, 파일, 기존 캠퍼스 권한은 변경하지 않는다.

`calculator-directory.json`: 사용자가 제공한 74개 학교와 URL. 제공된 경로라는 뜻이며 전부 현행/공식/동작 검증 완료를 뜻하지 않는다. 이전 학년도, 로그인 필요, 건국 글로컬 전용을 별도 표시한다. 미확인 이유에 관한 제공자의 추측은 검증된 사실처럼 노출하지 않는다.

## 입력·보존

- 저장된 학생의 기존 `detailedTranscript`를 읽고 과목 단위로 편집한다. 평균 내신을 가상 과목으로 바꾸지 않는다.
- 중복 학기·과목, 누락 학년/학기/교과/유형, 잘못된 등급·성취도는 산출 보류한다.
- 학기별 동일 과목은 각각 인정한다. 반영 과목과 제외 이유, 실제 부족분 보충 수를 보존해 표시한다.
- 전체 입력 확인 전 산출하지 않는다. 과목/조건 변경 시 결과를 무효화하고 다시 확인한다.
- 직접 입력/예시는 세션 메모리에만 존재한다. `선택 학생에 성적 저장`을 누를 때에만 기존 `desktopAPI.updateStudent` 및 인증된 `/api/data`를 사용한다. 새 저장 계약 없음.
- 학생부 외 기존 필드는 기존 updateStudent 병합 계약으로 보존한다. 저장 오류는 입력을 지우지 않는다. 계산 작업은 AI·파일·외부 학생정보 전송을 하지 않는다.
- 캠퍼스 데이터 교체 시 draft와 비동기 세대를 초기화한다. 화면 이동의 늦은 import가 다른 화면에 결과를 쓰지 못한다.
- 결과 복사와 PNG 상담지는 같은 계산 결과/버전/출처를 사용한다. 저장된 과거 사례·대학 자료는 재작성하지 않는다.

## 정렬

중부대 4전형은 `공개 전년도 최저 반영등급 - 현재 반영등급` 내림차순으로 비교한다. 등급 숫자가 작을수록 좋은 성적이다. 같은 기준의 역사적 비교일 뿐 올해 합격선이나 합격 가능성은 아니다. 다른 대학의 배점 백분율, 최저/평균/70%컷을 섞어 순위로 만들지 않는다. 비교검증 전인 서원대는 환산 완료 그룹에 따로 표시한다.

## 검증

- 순수 엔진 24개 테스트: 공식 예제, 모든 점수표 경계, 진로성취, 상위과목, 미이수 보충, 중복, 빈 입력, 학년도·5등급제 차단, 순위/디렉터리 무결성.
- 공식 계산기 실제 합성 입력: 중부대 `[4,3,4,3,5,2,2,4,5,4]` = 3.6등급, 180/200점 일치. 서원대 국수 `[1,2,3,4]`, 영어 `[1,2]`, 탐구 `[3,9]` = 3.13등급 일치. 서원대 점수 175.6/200은 공식 모집요강의 과목별 점수표로 검증(공식 계산기는 등급만 표시).
- `scripts/check-verified-grades-browser.mjs`: 격리된 합성 API에서 74개 검증. 320/390/768/1024/1440/1920px, 겹침/넘침, 저장·재접속, 실패시 입력 보존, HTML 삽입 무실행, 복사·PNG, 32회 화면 전환, 계산 API 호출 0, 외부 요청 0.
- 기존 `scripts/check-admissions-browser.mjs`: 197개 검증 통과. 관리목록 제한, 수시/정시 상세·외부 링크·주요 탭 회귀 유지.
- 빌드/타입/추가 JS lint 통과. 전체 CI 및 운영 배포·인증 접속 검증은 PR/최종 보고에서 실제 완료 상태를 별도로 기록한다.

## 미완료

나머지 대학/전형의 공식 학년도·캠퍼스·학과별 규칙과 전년도 비교 기준 검증, 2028/5등급제, 정시·검정고시, 실기·면접·수능최저 포함 종합 지원 판단. URL만으로 자동 계산이 완성되는 것은 아니다. 추가 검증된 규칙을 같은 카탈로그/엔진에 확장하며, 미검증 결과를 임의 점수로 대체하지 않는다.
