# 출석부 셀 서식·반복 수업칸 보존

기준 main: `b8dd9ea99a1b3aee6acc1588f346a7c6e2d0845c` (PR #230 다음).

## 원인과 변경

- 종전에는 학생 한 행의 배경을 수업/비수업 두 가지로 축약했다. 이제 학생 행 × 요일 × 수업칸별 원본 서식을 채집해 주황색 수업, 흰색 빈칸, 회색 비수업 영역을 구분한다. 원본 첫 28일의 반복 근거에서 다수 색상·서식을 사용하며 휴일 한 번이 정규 패턴을 덮어쓰지 않는다.
- `보` 등 일회성 출결/보강 문자가 하나라도 있으면 나머지 색상 근거를 무시하던 추론을 수정했다. 정규 색상 근거를 먼저 사용하고 명시적인 예외 문자는 수업일 근거에서 제외한다. 원본에 없는 수업요일을 자동 추가하지 않는다.
- 날짜 열이 늘 때 과거 오른쪽 영역의 테두리가 새 31일 칸에 남았다. 새 달력 몸체도 원본 요일/수업칸의 font/alignment/number format/border를 복사한다. 첫·마지막 외곽선만 실제 새 경계에 연결한다. 학생 정보 열, 학생 순서, 행 높이, 원본 ZIP 파트는 유지한다.
- `휴원`, `휴원중`, `휴원 중`, `퇴원`은 정규 요일 확인 대상에서 제외한다. 달력 전체를 병합한 상태 행의 문구와 병합 폭을 보존한다. 알 수 없는 부분 병합을 지우지 않고 원본 날짜칸 유지 또는 Excel 검수로 안내한다.
- 새 달에는 이전 달력 상단의 연휴/휴강/보강 등 날짜성 메모를 복사하지 않는다. 해당 메모 범위에만 적용하고 알 수 없는 고정 라벨은 보존한다. 생성본에만 적용하고 UI에 알린다. 같은 달을 생성하면 해당 메모와 병합, 해당 날짜의 배경을 유지한다. 다음 달 공휴일은 추측하지 않는다.
- 미리보기의 열 폭은 이미 여백을 포함하는 OOXML width에 5px을 중복 추가하지 않도록 수정했다. 계산식 근거: [Microsoft Column.width](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.column?view=openxml-3.0.1). 기본 digit width 7px 가정은 기존대로이며 특수 Normal 폰트의 실제 Excel 측정과는 차이가 날 수 있다.
- rich-text 제목의 단일 run을 지우던 문제를 수정했다. 웹에서도 run font, 세로쓰기, 병합 셀의 오른쪽/아래 테두리를 반영하고 공통 앱 table 스타일이 원본에 없는 선을 넣지 않도록 한다. 얇은 선/가는 선/굵은 선을 구분한다. 원본 Excel 스타일 정의는 삭제·변경하지 않고 필요한 파생 스타일만 추가한다.

## 안전한 월 변경 정책

- 원본 파일은 덮어쓰지 않는다. 출력은 별도의 새 workbook이다.
- 이전 달의 실제 출결/보강 문자는 새 달에 그대로 옮기지 않는다. 정규 시간표와 휴원 상태만 유지한다.
- 정규횟수/총횟수/5주차 등 수동 입력 숫자는 원본을 유지한다. 계약 횟수인지 실제 출석 합계인지 추측해 재계산하지 않는다. 수식은 기존 안전 정책과 Excel 재계산을 따른다.
- 근거가 불확실한 슬롯을 실제 수업이라고 확정하지 않는다. 기존 수업요일 확인 절차와 복잡한 수식 양식의 원본 날짜칸 유지 제한도 유지한다.
- DB migration, 서버 API, D1/R2/FAMILY, 로그인/권한, 원본 파일 변경 없음.

- 최종 build/typecheck/전체 테스트/CI/Preview/production 관측은 PR evidence에 기록한다. 단순 생성 성공을 수업 일정 전체의 정확성 확인으로 표현하지 않는다.

## 남은 제한

브라우저와 Excel의 폰트·테두리 rasterization이 픽셀 단위로 완전히 같지는 않다. 그림/머리글/복잡한 수식 양식은 기존대로 Excel 다운로드 후 인쇄한다. 물리 프린터와 실제 Excel 앱 재계산은 이번 브라우저 검증과 별개다. 새로운 달의 공휴일·개별 보강 및 수동 합계는 담당자가 확인해야 한다.
