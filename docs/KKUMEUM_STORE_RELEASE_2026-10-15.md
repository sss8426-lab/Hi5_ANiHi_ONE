# 꿈이음 5단계: 앱스토어 · 플레이스토어 등록 준비 (2026-10-15)

꿈이음 보호자 앱(`/family/`)은 지금도 휴대폰 홈 화면에 설치되는 웹앱(PWA)입니다. 5단계는 이것을 스토어에서 받을 수 있게 하는 준비입니다. **계정 만들기, 결제, 약관 동의, 서명 키 만들기, 제출 버튼은 원장님이 직접 해야 합니다.** 그 직전까지를 이 문서와 저장소에 준비했습니다.

## 1. 추천 순서

1. **Android(플레이스토어) 먼저.**
   - 꿈이음 웹앱을 그대로 감싸는 TWA(Trusted Web Activity) 방식으로 냅니다. 화면, 알림, 로그인이 지금과 같습니다.
   - 앱을 고쳐도 다시 심사받을 필요가 거의 없습니다. 웹 배포만 하면 앱에도 반영됩니다.
2. **iPhone은 당분간 "홈 화면에 추가"로 안내.**
   - iOS 16.4 이상은 홈 화면에 추가한 웹앱도 알림을 받을 수 있습니다.
   - 앱스토어는 웹사이트를 감싸기만 한 앱을 자주 거절합니다(심사 지침 4.2). 그래서 iPhone 전용 기능(예: 사진 앨범 저장, 생체 인증)을 더할 때 Capacitor로 따로 내는 것을 권합니다.
   - Capacitor 빌드는 Mac과 Xcode가 있어야 합니다.

## 2. 저장소에 준비된 것

| 항목 | 위치 | 설명 |
|---|---|---|
| PWA 설치 정보 | `public/family/manifest.webmanifest` | 이름, 아이콘(192·512·maskable), 시작 주소, 색, 분류(education) |
| TWA 설정 | `mobile/android-twa/twa-manifest.json` | Bubblewrap이 읽는 설정. 주소·이름·색·아이콘·알림 위임 |
| 앱-사이트 연결 | `GET /.well-known/assetlinks.json` | Cloudflare 변수 `ANDROID_TWA_PACKAGE`와 `ANDROID_TWA_SHA256`이 있을 때만 응답하고, 없으면 404 |
| 스토어 스크린샷 | `D:\1.데이터 코어\프로그램데이터\꿈이음_스토어\screenshots\` | 가상 학생·보호자로 찍은 휴대폰 화면 (1080×1920) |

## 3. 원장님이 직접 할 일 (순서대로)

1. **Google Play Console 개발자 계정** 만들기. 한 번만 내는 등록비가 있고, 본인 확인을 거칩니다.
2. **패키지 이름 정하기.**
   - 설정에는 `com.hi5anihi.kkumeum`이 들어 있습니다.
   - 처음 올린 뒤에는 바꿀 수 없으니 바꾸려면 첫 업로드 전에 말씀해 주세요.
3. **앱 만들기 (개발 PC에서, 서명 키 비밀번호는 원장님이 직접 입력)**

   ```bash
   npm i -g @bubblewrap/cli
   ```

   ```bash
   bubblewrap init --manifest=https://hi5-anihi-one.sss8426.workers.dev/family/manifest.webmanifest
   ```

   ```bash
   bubblewrap build
   ```

   - 처음 실행하면 Java와 Android SDK를 설치할지 묻습니다. 예를 고릅니다.
   - 서명 키(keystore)를 만들 때 비밀번호를 정합니다. **이 파일과 비밀번호를 잃어버리면 앱을 업데이트할 수 없습니다.** 안전한 곳에 따로 보관하세요.
   - `bubblewrap init`은 저장소의 `mobile/android-twa/twa-manifest.json`과 같은 값으로 답하면 됩니다.
4. **Play App Signing의 SHA-256 지문을 서버에 넣기**
   - Play Console › 앱 무결성 › 앱 서명에서 "SHA-256 인증서 지문"을 복사합니다.
   - Cloudflare › Workers & Pages › hi5-anihi-one › 설정 › 변수에 두 값을 넣습니다.
     - `ANDROID_TWA_PACKAGE` = 패키지 이름
     - `ANDROID_TWA_SHA256` = 지문. 업로드 키와 앱 서명 키처럼 여러 개면 쉼표로 구분합니다.
   - 지문은 공개 정보라 비밀값이 아닙니다.
   - 넣은 뒤 `https://hi5-anihi-one.sss8426.workers.dev/.well-known/assetlinks.json`이 열리면 됩니다. 이게 맞아야 앱 위쪽에 주소창이 보이지 않습니다.
5. **스토어 등록 정보 입력.** 아래 4장 문구와 스크린샷을 씁니다.
6. **개인정보처리방침 주소 넣기.** 아래 5장 초안을 원장님이 확인·수정한 뒤 공개 주소로 올립니다. 말씀해 주시면 `/family/privacy.html`로 올려 드립니다.
7. **데이터 보안 설문** 입력 (6장 참고) → 내부 테스트 트랙에 올려 직원 휴대폰으로 확인 → 프로덕션 제출.
