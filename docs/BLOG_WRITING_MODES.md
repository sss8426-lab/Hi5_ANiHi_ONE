# 네이버 블로그 작성 가이드·생성 프롬프트·검수

기준일/원문 확인일: 2026-10-16. 기존 OpenAI 연결·DATA CORE 사진·저장 API를 사용한다. 게시·예약 발행은 하지 않는다.

## 작성 방식

- SEO 글 만들기: 독자의 검색 의도와 선택 기준, 제목·본문·사진 설명의 주제 일치. 키워드 반복 목표 없음.
- AEO 글 만들기: 핵심 질문의 직접 답변 → 이유 → 조건·방법 → 예외. FAQ와 질문형 소제목은 필요한 경우에만.
- GEO 글 만들기: 제공된 출처·기준 시점·대상·단위를 주장 가까이에 배치하고 사실·교육적 해석을 구분. 출처가 없으면 주장 제외 및 별도 확인 메모.

홈피드/검색/균형형은 기존 제목 방향이며 SEO/AEO/GEO와 독립적이다. 세 버튼은 같은 생성 API에 writingMode를 보내며 서버가 허용값을 검사한다. 미지정·알 수 없는 값은 SEO로 호환한다. 재작성과 초안 저장·열기에서도 작성 방식을 유지한다.

작성 버튼 영역에는 가로·세로 16px 간격을 두고, 화면이 좁으면 기존 줄바꿈 규칙으로 배치한다. 버튼 간격 변경 시 content-workflow.css의 캐시 버전도 함께 올린다.

2026-10-16 실제 운영 비교: 같은 학원 공간 사진 1장과 같은 요청으로 세 버튼 생성에 성공했지만, 모두 질문형 소제목 4개가 나와 구분이 약했다. 공통 원고·글 종류 지침의 질문형 강제를 제거하고 SEO 설명형, AEO 질문·짧은 직답·조건/예외, GEO 관찰·해석·추가 확인 구조를 명시했다. 이 편집 방식은 노출 공식이 아닌 운영 가설이다.

## 재사용 프롬프트

실제 실행 원본: worker/blog-writing-modes.ts의 blogWritingGuide. 기존 브랜드·사진·글 종류 양식 뒤에 추가해 고정 분량·키워드 횟수·소제목 수보다 우선한다.

입력: 목적·독자·핵심 질문, 캠퍼스, 확인된 사실, 사진 설명과 사용 권한, 실제 출처·자료 기준일, 확인된 상담 경로.
출력: 기존 JSON 계약 유지. strategy는 기획, titles는 제목 후보, lead/body는 공개 원고, missingInfo는 별도 검수 메모. 출처가 없거나 동의를 확인할 수 없으면 임의로 만들지 않는다. 세부 검수 결과를 본문에 섞지 않는다.

## 발행 전 체크리스트

각 항목을 통과 / 수정 필요 / 확인 불가로 검토한다. 자동 SEO 점수나 노출 확률이 아니다.

- 제목이 약속한 답과 독자의 질문이 본문에서 해결되는가?
- 실제 수업·작품 근거가 있고, 사실·의견·가설을 구분했는가?
- 캠퍼스·브랜드·상담 연락처가 일치하는가?
- 수치에 학년도·전형·대상·단위·출처가 있는가? 확인일을 지어내지 않았는가?
- 학생 이름·얼굴·작품·성적·상담 내용의 사용 권한이 확인됐는가?
- 실적·성장·후기·학생 발언을 추측하거나 생성 이미지를 실제 증거로 표현하지 않았는가?
- 키워드·브랜드 반복, 근거 없는 최고·1위·합격 보장, 낚시 제목이 없는가?
- 핵심 정보가 본문 텍스트에도 있고, 출처가 주장 가까이에 있는가?
- 본문에서 내부 메모를 제외했는가?

판정: 근거·권한 등 핵심 항목 확인 불가는 발행 보류, 수정 가능한 문구 문제는 수정 필요, 담당자 확인 완료 시 발행 가능. AI는 동의나 외부 사실의 진위를 확정하지 않는다. 기존 담당자 검수 흐름을 사용하며 이번 변경이 자동 발행 판정기를 새로 만든 것은 아니다.

## 근거의 적용 범위

- 공식 원칙: [네이버 서치어드바이저 콘텐츠 권장사항](https://searchadvisor.naver.com/guide/content-basic). 웹사이트 가이드이며 블로그 순위 공식이 아니다. 경험·유용성·정확한 제목·텍스트 정보·과장 방지 관점을 참고한다. 발행일은 페이지에 명시되지 않아 미확인.
- 공식 원칙: [Google 생성형 검색 가이드](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide). Google 검색과 자체 웹사이트 대상이며 네이버 공식 요구사항으로 설명하지 않는다.
- 연구: [GEO 논문](https://arxiv.org/abs/2311.09735), 2023년 최초 제출. 특정 실험 결과이며 네이버 AI 브리핑 인용 효과를 보장하지 않는다.
- 운영 가설: SEO/AEO/GEO 버튼 구분과 학원 편집 흐름. 노출 합격선이 아니며 실제 검색/홈피드 유입·문의 등을 기간과 출처를 기록해 관찰한다. 노출 수가 없으면 CTR을 계산하지 않는다.

사용자가 제공한 나머지 네이버 블로그 글·AI 브리핑 도움말·DAN 홈피드 발표·2차 해설은 이번에 원문을 전부 확인하지 않았다. 발표의 개선율·행동 이력 범위를 노출 공식이나 게시물 수명으로 사용하지 않는다. robots.txt·JSON-LD·llms.txt를 네이버 블로그 필수 조건으로 추가하지 않는다.
