# 출석부 자동생성 복구 (2026-09-15)

기준: origin/main `59a4b17eee3925cd91e1f85a0b69613ad61b5435`. 기존 작업 폴더의 미완료 변경은 유지하고 별도 worktree에서 수정했다.

## 확인된 원인과 수정

- 인식 가능한 시트 하나라도 다른 월이거나 미지원 시트가 있으면 workbook 전체를 거절했다. 이제 시트별 검사 결과와 선택 체크박스를 제공한다. 여러 달이 섞이면 가장 최근에 인식된 월의 시트가 기본 선택되며, 선택하지 않은 시트는 ZIP bytes 그대로 보존한다. 미지원 시트를 성공으로 표시하지 않는다.
- 월 정보가 없는 시트는 `원본 출석부 연도·월` 확인 후 인식을 재시도한다. 원본 연도/요일 근거와 충돌하면 거절한다. 현재 날짜로 원본 월을 추측하지 않는다.
- 일부 Excel 내보내기는 약 30행의 표 뒤에 1,000행까지 dimension/서식을 저장한다. 기존 로직은 빈 영역을 모두 출석표로 생성했다. 자동 adapter는 기존 인쇄영역, 실제 내용, 보이는 테두리, 병합 범위를 사용해 처리 범위를 결정한다. 바깥의 원본 서식 셀은 삭제하지 않는다. 인쇄영역이 없는 생성본에만 실제 표 범위를 설정한다.
- drawing relationship과 two-cell anchor를 검사한다. 학생정보 열 안에 있는 그림 또는 빈 drawing part는 원본 그대로 보존하며 열 재배치를 허용한다. 외부/누락/겹치는/미지원 anchor는 계속 차단한다.
- Excel 전체 범위 조건부서식은 128열/1,000행의 실제 표 제한과 구분해서 메타데이터로 읽는다. 부분 날짜 범위의 문자 조건부서식을 대상 날짜에 맞추고 상대참조 시작점을 갱신한다. 전체 Excel 범위를 실제 셀로 생성하지 않는다.
- 학년도 제목 갱신, 같은 폭에서 주말 병합 중복 생성, 수식 셀의 실수 삭제를 수정했다.

## 복잡한 수식 양식

`원본 날짜칸 유지`는 사용자가 명시적으로 선택하는 별도 복구 옵션이다. 31일 칸이 있는 양식에 한해 기존 열 폭/병합/수식 위치를 유지하며 날짜·요일·수업 표시를 갱신한다. 수식 캐시만 지우고 Excel 재계산을 요청한다.

이 옵션은 주말 다중 수업칸을 새로 재배치하지 않는다. 해당 제한을 선택 전과 생성 결과에 표시한다. 복잡한 수식이 있으면 Excel 다운로드 후 인쇄하도록 안내한다. 기본 자동 모드의 요일별 다중 슬롯 재배치와 기존 안전 차단은 유지한다.

## 검증

- 로컬 실제 파일 5개를 읽기 전용으로 확인. 4개는 기본 선택된 시트 자동 생성, 1개는 원본 날짜칸 유지로 2개 시트 생성에 성공했다. 학생 수업요일 확인은 검증용 입력이며 실제 정규 수업요일을 확인한 것으로 간주하지 않는다.
- 실제 파일 원본 hash 동일, 비선택 ZIP part 동일, 수식 text 보존 확인. 생성 결과는 메모리에서 검사하며 실제 파일명/학생명/시트명은 로그·문서·커밋에 기록하지 않는다.
- 실제 파일 5개를 Chromium UI에서도 불러오기 → 필요한 요일 확인 → 만들기로 검증했다. 합성 인증 context를 사용했고 운영 로그인 검증은 아니다. 파일별 로컬 관측 시간은 약 0.4~1.5초였으며 장치/파일에 따라 달라진다. 실제 데이터 스크린샷은 저장하지 않았다.
- 합성 UI: 1920/1440/1280/1024/820/768/430/390, 시트 선택/월 확인/잘못된 월 거절/수식 복구/다운로드 재열기/인쇄 iframe/Chromium PDF/권한/캠퍼스 변경 통과. 실제 사용자 그림과 수식의 출력은 Excel 인쇄로 안내한다.
- 로컬 npm ci, build, typecheck, public JS 65개 node --check, 변경 출석부 파일 ESLint, Wrangler dry-run 통과. 전체 테스트 456/456 통과(출석부 41개 포함). CI/Preview/production 결과는 PR evidence에 기록한다.

## 남은 제한

- 한 시트에 여러 표가 나란히 있는 2개 시트와 원본 월·요일 근거가 불일치하는 1개 시트는 미지원으로 표시한다. 해당 파일의 정상 시트는 선택해서 생성할 수 있다.
- 월이 없는 시트는 사용자의 원본 월 확인이 필요하다.
- `원본 날짜칸 유지`로 생성한 다중 슬롯은 Excel에서 주말 수업칸을 확인해야 한다.
- 실제 Excel 데스크톱 앱의 수식 재계산과 물리 프린터 출력은 확인하지 않았다.
- DB migration, 운영 D1/R2/FAMILY 변경, 계정/권한 변경, 원본 파일 덮어쓰기는 없다.
