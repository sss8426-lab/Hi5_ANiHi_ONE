# 꿈이음 3단계: 신청/동의서 · 학원 일정 (2026-10-14)

아이소식의 "신청/동의서"와 "일정"을 꿈이음에서 대신하기 위한 단계입니다.

## 신청/동의서

### 교직원 (꿈이음 › 더보기 › 신청/동의서)

- **새로 만들기**에서 다음을 정합니다.
  - 종류: 신청서 또는 동의서.
  - 제목, 안내글, 마감일(선택).
  - 질문: 최대 15개. 종류는 하나 고르기 · 여러 개 고르기 · 직접 쓰기이고, 질문마다 필수 여부를 고릅니다.
  - 받을 대상: 캠퍼스 전체 · 반 · 학생 중 하나.
- 보내면 대상 학생의 보호자에게 알림(`kind: form`)이 갑니다. 알림을 누르면 `/family/?openForm=<id>`가 열립니다.
- **제출 현황**에서 볼 수 있는 것:
  - 대상 · 제출 · 미제출 · 동의 수.
  - 고르기 질문별 집계.
  - 학생별 답.
- 제출 현황 화면에서 할 수 있는 일:
  - 미제출 보호자에게 다시 알림.
  - 마감하기 / 다시 받기.
  - 지우기: 제출이 하나도 없을 때만.
  - 엑셀용 CSV 받기.
- 권한:
  - 캠퍼스 전체 대상은 원장·관리자만 보낼 수 있습니다.
  - 선생님은 담당 반 학생에게만 보내고, 담당 반 학생의 현황만 봅니다.
  - 마감과 삭제는 만든 사람이나 원장·관리자만 할 수 있습니다.

### 보호자 (꿈이음 앱 › 더보기 › 신청/동의서)

- 자녀마다 한 번 제출합니다. 마감 전에는 다시 제출해서 고칠 수 있습니다.
- 동의서는 "동의합니다 / 동의하지 않음"을 꼭 골라야 합니다.
- 마감된 양식은 제출한 기록만 목록에 남습니다.
- 아직 제출하지 않은 양식 수가 더보기 버튼에 숫자로 표시됩니다.

### 저장 (FAMILY_DB, 처음 쓸 때 자동 생성)

- `family_forms`: 양식.
- `family_form_targets`: 대상 (campus / class / student).
- `family_form_responses`: 제출. 같은 양식과 학생 조합은 1건뿐입니다.

기존 개인정보 동의 기능(`consents`, `/api/kkumeum/consents`)과는 별개입니다.

## 학원 일정 (꿈이음 앱 › 더보기 › 학원 일정)

- 보호자에게는 자녀가 다니는 캠퍼스의 다음 일정만 월별로 보입니다.
  - 휴일: 공휴일 자동 동기화와 학원이 등록한 휴원.
  - 공휴일 수업: "정상 수업"으로 표시됩니다.
  - 교직원이 **학부모에게도 보이기**를 체크한 일정 (`metadata.familyVisible`).
- 회의 · 홍보 같은 내부 일정과 개인 일정은 보이지 않습니다. 보호자 응답에는 제목, 날짜, 시간, 장소, 캠퍼스 이름만 담깁니다.
- 체크하는 곳은 두 군데입니다.
  - DATA CORE 학원 공통 일정의 일정 등록 창.
  - 꿈이음 › 더보기 › 일정관리의 일정 등록.

| 교직원 | `GET/POST /api/kkumeum/forms` (`campusId`) |
| 교직원 | `GET/PATCH/DELETE /api/kkumeum/forms/:id` |
| 교직원 | `POST /api/kkumeum/forms/:id/remind` |
| 보호자 | `GET /api/family/forms` |
| 보호자 | `GET /api/family/forms/:id` |
| 보호자 | `POST /api/family/forms/:id/responses` (`{studentId, answers, consent}`) |
| 보호자 | `GET /api/family/schedule?month=YYYY-MM` |
