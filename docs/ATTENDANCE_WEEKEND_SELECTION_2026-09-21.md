# 출석부 수업요일 확인: 주말 최대 3타임

기준: origin/main `5bdc0aaeb21e76071644a4a7ec4389cb188be29a`.

## 동작

- 확인이 필요한 학생에게 평일 5개, 토(1~3), 일(1~3) 선택을 제공한다.
- 괄호 번호는 시간대 예약이 아니라 수업 횟수 선택이다. 토요일 2개 선택은 토요일 수업칸 2개 표시를 뜻한다. Excel 머리글에는 괄호 번호를 넣지 않는다.
- 선택은 학생별 `counts`로 전달한다. 기존 문자열 요일 override는 호환하며 자동 인식된 다른 학생의 channels/slots는 바꾸지 않는다.
- 한 행 양식은 해당 시트에 필요한 최대 주말 칸 수까지 열을 확장하고 학생마다 선택한 개수만 색칠한다. 이미 있는 다른 학생용 칸은 줄이지 않는다.
- 학생 한 명이 여러 행을 쓰는 양식은 기존 행을 먼저 활용한다. 타임 수를 모든 행에 반복 적용하지 않는다.
- 주간 구분 열/휴무일 생략 양식도 기존 adapter를 재사용한다. 사용자가 직접 선택한 생략 요일만 추가할 수 있으며 새 타임의 스타일은 같은 요일의 기본 칸에서 복사한다. 그 요일 표본이 없으면 기존 기본 날짜칸을 사용한다.
- 같은 달로 생성해도 수동 확인값이 반영된다. 확인 후 `수정`으로 다시 선택할 수 있으며 취소는 저장된 선택을 바꾸지 않는다.
- `원본 날짜칸 유지`에서 선택한 횟수를 담을 수 없으면 생성을 막고 옵션 해제를 안내한다. 지원하지 않는 수식/개체의 기존 안전 차단은 유지한다.

## 보존

브라우저 메모리에서 새 workbook만 생성한다. 원본 파일, 학생 순서, 개인정보 열, 기존 인쇄 설정과 비대상 ZIP 파트를 보존한다. DB/R2/API/계정/권한 변경 및 migration 없음. 실제 학생 데이터는 테스트 fixture나 로그에 포함하지 않는다.
