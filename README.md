# 입시 컨설팅 대시보드 MVP

미술·만화·웹툰·게임일러스트 계열 입시 상담을 위한 웹 기반 1차 MVP입니다.
학생 성적을 입력하면 지원 가능 대학을 계산하고, 대학 상세 정보와 합격·불합격 사례를 비교할 수 있습니다.

## 1. 프로젝트 폴더 구조

```text
app/
  data/
    admissions.ts        예시 대학, 전형, 합격·불합격 사례 데이터
  lib/
    recommendations.ts   합격 가능성 계산, 지원 등급 분류, 사례 검색 로직
  globals.css            전체 UI 스타일
  layout.tsx             페이지 기본 정보
  page.tsx               상담 대시보드 화면과 상호작용
db/
  schema.ts              향후 DB 연결을 위한 기본 위치
public/
  favicon.svg            브라우저 아이콘
```

## 2. 실행 방법

의존성 설치 후 개발 서버를 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 개발 서버가 알려주는 로컬 주소로 접속하면 됩니다.

## 3. 주요 기능

- 학생 기본 정보, 내신, 교과 등급, 실기 점수, 희망 대학 입력
- 지원 가능 대학 자동 계산 및 가능성 높은 순 정렬
- 안정, 적정, 소신, 도전 지원 등급 표시
- 대학 클릭 시 모집인원, 반영비, 반영 과목, 일정, 경쟁률 표시
- 전년도와 달라진 모집 조건 경고 표시
- 합격 사례와 불합격 사례 좌우 비교
- 실기 작품 이미지 영역 표시
- 수시 6회 기준 지원 전략 요약
- 관리자 화면에서 선택 대학 데이터 수정
- 수정한 대학 정보가 추천 결과와 상세 화면에 즉시 반영

## 4. 데이터 구조

현재는 `app/data/admissions.ts`에 예시 데이터를 두었습니다.
실제 서비스에서는 다음 모델로 분리하는 것을 기준으로 삼으면 됩니다.

- `students`: 학생 기본 정보
- `universities`: 대학 기본 정보
- `departments`: 학과 정보
- `admission_years`: 학년도
- `admission_types`: 수시, 정시, 실기전형 등 모집 유형
- `admission_rules`: 성적/실기 반영비, 반영 과목, 일정
- `student_scores`: 학생 내신 및 과목별 성적
- `student_skill_scores`: 실기 평가 점수
- `applications`: 학생별 지원 대학
- `acceptance_cases`: 익명 합격·불합격 사례
- `artworks`: 실기 작품 이미지와 평가 코멘트
- `consulting_records`: 상담 기록
- `favorite_universities`: 관심 대학
- `competition_rates`: 연도별 경쟁률
- `admin_users`: 관리자 계정
- `change_logs`: 데이터 변경 이력

## 5. 실제 서비스 전환 시 필요한 작업

- 현재 예시 데이터를 DB 테이블과 API로 교체
- 관리자 저장 기능을 서버 저장 방식으로 전환
- 로그인, 권한, 개인정보 보호 정책 적용
- 실기 작품 이미지 업로드 저장소 연결
- 엑셀 업로드 및 데이터 검증 기능 추가
- 상담 리포트 PDF 출력 기능 추가
- 합격 가능성 계산식을 실제 누적 데이터 기반으로 고도화
